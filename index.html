03 / Experience

做過的工作

PROJECT EXPERIENCE

後端開發與系統串接

我參與過交易報表、金融資料處理、票務和通知服務，也做過網頁與後端的串接。

  • ATM／支付系統整合：接觸交易訊息處理、微服務串接及事件驅動流程。

  • 協助新人熟悉系統和開發流程，討論實作時遇到的問題。

找我聊聊你的專案

我接受外包合作，包括新功能開發、修改現有系統和 API 串接。可以幫忙的項目有：

後端系統開發
